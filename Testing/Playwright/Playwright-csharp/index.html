    Playwright with C#

    dotnet add package Microsoft.Playwright
playwright install
playwright install msedge  # Optional for Edge channel

    Project Setup

    1. Install Playwright CLI :
        dotnet tool install --global Microsoft.Playwright.CLI
    1. Initialize Playwright:
        playwright install
    1. Create an directory
        dotnet new Nunit -n PlaywrightPractice
    1. Go to created directory: 
        cd PlaywrightPractice
    1. Add dependencies in project:
        dotnet add package Microsoft.Playwright
    playwright install
    playwright install msedge  # Optional for Edge channel

    1. Write your Script

    2. Run the test

        dotnet run
    1. Basic Syntax: ```csharp using Microsoft.Playwright;

    class Program { public static async Task Main() { using var playwright = await Playwright.CreateAsync(); var browser = await playwright.Chromium.LaunchAsync(new BrowserTypeLaunchOptions { Headless = false }); var context = await browser.NewContextAsync(); var page = await context.NewPageAsync(); await page.GotoAsync("https://example.com"); await page.ScreenshotAsync(new PageScreenshotOptions { Path = "screenshot.png" }); await browser.CloseAsync(); } } ```

    Launch Options & Maximizing Window

    Set Arguments:

    var launchOptions = new BrowserTypeLaunchOptions
{
    Headless = false,
    Args = new[] { "--start-maximized" }
};

    Set Viewport Size:

    var contextOptions = new BrowserNewContextOptions
{
    ViewportSize = new ViewportSize { Width = 1920, Height = 1080 }
};

    Browser Setup

    • Edge:
    await playwright.Chromium.LaunchAsync(new BrowserTypeLaunchOptions { Channel = "msedge", Headless = false });
    • Chrome with path:
    await playwright.Chromium.LaunchAsync(new BrowserTypeLaunchOptions { ExecutablePath = "path-to-chrome", Headless = false });
    • Persistent Context (No Incognito):
    await playwright.Chromium.LaunchPersistentContextAsync("user-data-dir", new BrowserTypeLaunchPersistentContextOptions { Headless = false });

    Locators

    • Store and reuse locator:
    var locator = page.Locator("#inputEmail");
await locator.FillAsync("email@example.com");
    • Direct action:
    await page.FillAsync("#inputEmail", "email@example.com");

    Types: - ID: #elementId - Class: .className - Attribute: [type='email'] - CSS & XPath both supported

    Page Methods

    await page.FillAsync("#username", "admin");
await page.ClickAsync("text=Submit");
var text = await page.Locator("h1").TextContentAsync();
bool visible = await page.Locator("#element").IsVisibleAsync();

    🧭 Navigation Methods

    GotoAsync()

    Navigate to a URL.

    await _page.GotoAsync("https://example.com");

    With options:

    await _page.GotoAsync("https://example.com", new PageGotoOptions {
    WaitUntil = WaitUntilState.NetworkIdle,
    Timeout = 10000
});

    📋 Locator Methods

    Locator()

    Select elements.

    var button = _page.Locator("button#submit");

    Supports: - CSS: ".btn.primary" - Text: "text='Login'" - XPath: "//div[@id='main']" - Regex: new Regex("Log In")

    AllAsync()

    Returns all matching elements.

    var elements = await _page.Locator("li").AllAsync();

    CountAsync()

    Count matching elements.

    int count = await _page.Locator(".product").CountAsync();

    ClickAsync()

    Click an element.

    await _page.Locator("#submit").ClickAsync();

    With options:

    await _page.Locator("#submit").ClickAsync(new LocatorClickOptions {
    Button = MouseButton.Right,
    ClickCount = 2,
    Timeout = 5000
});

    FillAsync() & TypeAsync()

    Fill or type into input fields.

    await _page.Locator("#email").FillAsync("test@example.com");
await _page.Locator("#name").TypeAsync("John Doe");

    InnerTextAsync() / TextContentAsync()

    Get text values.

    string visibleText = await _page.Locator("h1").InnerTextAsync();
string allText = await _page.Locator("h1").TextContentAsync();

    State Checks

    await _page.Locator("#submit").IsVisibleAsync();
await _page.Locator("#submit").IsEnabledAsync();
await _page.Locator("#agree").IsCheckedAsync();
await _page.Locator("#input").IsEditableAsync();

    📸 Screenshots

    await _page.ScreenshotAsync(new PageScreenshotOptions {
    Path = "screenshot.png",
    FullPage = true

    🔢 Title & URL

    string title = await _page.TitleAsync();
string url = _page.Url;

    ⌛ Wait Methods

    await _page.WaitForTimeoutAsync(2000); // 2 seconds
await _page.WaitForSelectorAsync("#login-form");

    🔍 XPath Reference

    Syntax Meaning
    .. Parent
    /parent::* Explicit parent
    /ancestor::div Any ancestor div
    /following-sibling::li Following <li> siblings
    [1] First match
    //li[text()='Banana'] <li> with exact text
    //li[contains(text(), 'Ban')] <li> containing text
    /../../.. Go up 3 levels
    preceding-sibling:: Previous siblings

    🔁 Locator Chaining

    _page.Locator("div.card").Nth(2);
_page.Locator("ul > li").First;
_page.Locator("ul > li").Last;

    Waits and Assertions

    await page.WaitForSelectorAsync("#element");

    ❗ Common Error: TargetClosedException

    This happens if: - Page/browser was closed too early - Async operations not awaited properly - Cleanup ran too soon

    Fix: Await all async calls, ensure correct test lifecycle management.

    👨‍💻 Base Class Structure Example

    public class PlaywrightBase
{
    protected IPlaywright _playwright;
    protected IBrowser _browser;
    protected IBrowserContext _context;
    protected IPage _page;

    public async Task StartAsync(bool headless = true)
    {
        _playwright = await Playwright.CreateAsync();
        _browser = await _playwright.Chromium.LaunchAsync(new BrowserTypeLaunchOptions {
            Channel = "msedge",
            Headless = headless
        });
        _context = await _browser.NewContextAsync();
        _page = await _context.NewPageAsync();
    }

    public async Task StopAsync()
    {
        await _context?.CloseAsync();
        await _browser?.CloseAsync();
        _playwright?.Dispose();
    }
}

    📘 Data-Driven Testing with Playwright + NUnit (C#)

    This document covers how to perform data-driven testing using Playwright with C# and NUnit, along with multiple ways to provide test data.

    ✅ What is Data-Driven Testing?

    Data-driven testing allows running the same test logic with multiple sets of input data. This helps in increasing test coverage with less code duplication.

    ✅ Basic Example Using [TestCase]

    Use when you have small static test data.

    [TestCase("user1", "pass1")]
[TestCase("user2", "pass2")]
public void LoginTest(string username, string password)
{
    // Your Playwright test logic here
}

    ✅ Using [TestCaseSource] with Static Property

    public static IEnumerable<TestCaseData> LoginData =>
    new List<TestCaseData>
    {
        new TestCaseData("user1", "pass1"),
        new TestCaseData("user2", "pass2")
    };

[Test, TestCaseSource(typeof(MyDataClass), nameof(MyDataClass.LoginData))]
public void LoginTest(string username, string password)
{
    // Test logic
}
    • typeof(MyDataClass) tells NUnit where to find the data.
    • nameof(MyDataClass.LoginData) specifies the exact member to use.

    ✅ Using Static Method as Data Source

    Allows conditional logic or dynamic data creation.

    public static IEnumerable<TestCaseData> GetLoginData()
{
    yield return new TestCaseData("user1", "pass1");
    yield return new TestCaseData("user2", "pass2");
}

[Test, TestCaseSource(typeof(MyDataClass), nameof(MyDataClass.GetLoginData))]

    ✅ Using JSON File for Test Data

    🔹 JSON Example

    [
  { "username": "user1", "password": "pass1" },
  { "username": "user2", "password": "pass2" }
]

    🔹 C# Code

    public static IEnumerable<TestCaseData> LoginDataFromJson()
{
    var json = File.ReadAllText("testdata.json");
    var users = JsonConvert.DeserializeObject<List<LoginModel>>(json);
    foreach (var user in users)
    {
        yield return new TestCaseData(user.Username, user.Password);
    }
}

    ✅ Using Environment Variables or GitHub Secrets

    Good for use in CI/CD pipelines to avoid hardcoding sensitive data.

    public static IEnumerable<TestCaseData> SecretsData()
{
    var username = Environment.GetEnvironmentVariable("USERNAME");
    var password = Environment.GetEnvironmentVariable("PASSWORD");
    yield return new TestCaseData(username, password);
}

    ✅ Reading from Database

    Use when test data is stored in a DB:

    public static IEnumerable<TestCaseData> LoginDataFromDb()
{
    using var conn = new SqlConnection("connection-string");
    conn.Open();
    var cmd = new SqlCommand("SELECT username, password FROM users", conn);
    var reader = cmd.ExecuteReader();

    while (reader.Read())
    {
        yield return new TestCaseData(reader["username"], reader["password"]);
    }
}

    🧠 Summary of Data Source Options

    Method Use Case
    [TestCase] Simple inline data
    TestCaseSource (property) Shared static list
    TestCaseSource (method) Conditional or dynamic data
    JSON File Separate, manageable test data
    Environment Variables Secure, pipeline-friendly data
    Database or API Live or external data for advanced testing

    Using Secrets in GitHub Actions

    env:
  USERNAME: ${{ secrets.USERNAME }}
  PASSWORD: ${{ secrets.PASSWORD }}

    And in your test code:

    var username = Environment.GetEnvironmentVariable("USERNAME");
var password = Environment.GetEnvironmentVariable("PASSWORD");
