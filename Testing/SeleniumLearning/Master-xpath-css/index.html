    Xpath

    1. What is XPath? A query language which is used to find a node or set of nodes in XML/HTML document

    2. Absolute and Relative Xpath: 

      1. Absolute XPath: Uses the complete path starting from root (/html) to desired element       
      Syntax: /html/body/div[2]/div/...

2. Combination of Relative and Absolute XPath         
      Example: //span[@id='u123']/div[1]/a

    Relative Xpath

    1. Relative XPath Using Node Attributes

          Syntax:
    //TagName[@Attribute Name="Attribute Value"]

    2. Relative XPath Using Text 

          Syntax:
    //TagName[text()="Text"]

    3. Dynamic Elements: Elements with dynamic property-values and/or text 

        1. Using 'and' Operator
     Syntax: 
     //TagName[@Att1='Value1' and @Att2='Value2']
     //TagName[@Att='Value' and Text()='Value']

  2. Using 'or' Operator
      Syntax: 
     //TagName[@Att1='Value1' or @Att2='Value2']
     //TagName[@Att='Value' or Text()='Value']

  3. Using 'contains'
     Syntax:
     //TagName[contains(@Att,'Partial Value')]
     //TagName[contains(text(),'Partial Value')]

  4. Using 'starts-with' 
      Syntax:
     //TagName[starts-with(@Att,'Starting Value')]
     //TagName[starts-with(text(),'Starting Value')]

  5. Hybrid
      Syntax:
      //TagName[contains(@Att1,'Partial Value') and starts-with(text(),'Starting Value')]  
      //TagName[@Att1='Value' or starts-with(@Att2,'Starting Value')]
      //*[@Att='Value']

    4. XPath Axes: 

      a. Parent and Child Relation         
    Syntax:           
    //Node1/child::*          
    //Node1/parent::*

b. Ancestor and Descendant Relationship       
    Syntax:       
    //Node1/ancestor::*       
    //Node1/descendant::*

c. Preceding and Following        
    Syntax:       
    //Node1/preceding::*          
    //Node1/preceding-sibling::*          
    //Node1/following::*          
    //Node1/following-sibling::*

    CSS selector:

    1. What is CSS and CSS Selector?
      CSS (Cascading Style Sheets): Describes presentation of elements mentioned in HTML
      CSS Selector: Pointer for applying the styling mentioned in CSS

    2. Creating CSS Selector Using Attributes

      Syntax: TagName[Att1=Value]
In case Att1 is 'id' or 'class' then we can use following symbols:
    id => # (hash)
    class => . (dot)
Examples: 1. div#u123   2. span.layerParent

    3. Creating CSS Selectors for Dynamic Elements

        1. Using partial value of attribute (Symbol - *)
      Example: TagName[Att1*='Partial Value']

  2. Using starting value of attribute (Symbol ^)
      Example: TagName[Att1^='Starting Value']

  3. Using ending value of attribute (Symbol $)
      Example: TagName[Att1$='Ending Value']

    4. Creating CSS with Multiple Attributes

        a. ANDING the Attributes (No Symbol Required)
      Syntax: TagName[Att1=Value][Att2=Value]

  b. ORING the Attributes (',' will work as 'OR')
      Syntax: TagName[Att1=Value], TagName[Att2=Value]

    5. Advanced CSS Selectors

        1. Using only TagName and Attribute Name

  2. Node1,Node2 => Matches all Node1s and Node2s

  3. Node1 Node2 => Matches all Node2s which are descendant of Node1

  4. Node1>Node2 => Matches all Node2s which are children of Node1

  5. Node1+Node2 => Matches sibling Node2 placed immediately after Node1

  6. Node1~Node2 => Matches all sibling Node2s placed after Node1

    6. using Node Child Numbering 

        1. Node1:first-child 
      => Selects all Node1s who are first child of their parent

  2. Node1:last-child 
     => Selects all Node1s who are last child of their parent

  3. Node1:nth-child(n) 
     => Selects all Node1s who are nth child of their parent

    SelectorsHub Tool

    What is SelectorsHub?

    SelectorsHub is a free-to-use browser extension that auto-suggests all the possible combinations of attributes, text, siblings, etc. to build selectors within seconds.

    Features

    SelectorsHub offers unique features that make it one of the best XPath tools available.

    1. Auto Suggest:

      SelectorsHub is an open-source browser extension that auto-suggests all possible combinations of attributes, text, siblings, etc., to build selectors within seconds.

    2. Compiler for Selectors

      Previously, no tool could indicate what was wrong with a selector. Developers had to become experts to understand their mistakes. DevTools would only suggest 0 matching nodes for an incorrect selector pattern. Now, SelectorsHub provides a Selector Compiler that displays correct error messages and highlights incorrect or missing elements in the selector.

    3. ShadowDOM Support

      SelectorsHub allows writing and verifying CSS Selectors for ShadowDOM elements. Users can inspect and verify selectors for ShadowDOM elements.

    4. iFrame Support

      SelectorsHub helps identify whether an inspected element is inside an iframe.

    5. SVG Element Support

      SVG (Scalable Vector Graphics) elements require different XPath patterns. SelectorsHub assists in identifying the correct format while inspecting SVG elements.
