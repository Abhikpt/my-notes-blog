    Introduction to Selenium

    Selenium is a powerful testing tool used to automate test scripts for web applications across various browsers and platforms. It does not support desktop applications.

    You can download Selenium from www.seleniumhq.org.

    Significance of Selenium

    • Open-source: It's a free and open-source tool for web application testing.
    • Cross-platform and multi-language support: It supports executing scripts on various operating systems and in major programming languages like C#, Ruby, Java, Python, Perl, and JavaScript.
    • Cross-browser testing: It enables executing scripts across different browsers.

    Selenium Components

    Selenium consists of the following components:

    • Selenium IDE (Integrated Development Environment)
    • Selenium RC (Remote Control)
    • Selenium WebDriver
    • Selenium Grid

    Selenium IDE

    • Selenium IDE is a record-and-playback tool, available as an add-on for Firefox and Chrome.
    • It allows recording user interactions and playing them back as test scripts.
    • Recorded scripts can be exported to various programming languages like Java, C#, Ruby, and Python.

    Selenium RC (Selenium 1.0)

    • Selenium RC (Remote Control), also known as Selenium 1.0, was the core Selenium framework before WebDriver.
    • It supports web browsers that can interpret HTTP requests and doesn't require browser-specific drivers.
    • It uses a Selenium server to start, stop, and control browsers automatically.
    • Disadvantage: Requires a running RC server to execute test scripts.
    • Components: Script -> Selenium Server -> Application/Browser
    • Setup:
      1. Download the Selenium server JAR file.
      2. Run the server.
      3. Execute the script.
      4. Example code: driver = new RemoteWebDriver(_testsetting.GridUri, new ChromeOptions());

    Selenium Grid

    • Selenium Grid is designed for running test scripts in parallel across multiple test environments, browsers, operating systems, and machines.
    • The central machine controlling the tests is called the "hub," and the remote machines executing the tests are called "nodes."
    • Primarily used for performance testing.

    Selenium WebDriver

    • Selenium WebDriver enables creating and executing test cases using element/object locators.
    • It interacts directly with the web browser without an external server, making it faster than Selenium RC.

    Selenium Commands

    Selenium commands are used to automate web browser interactions. They can be categorized as follows:

    1. Application Commands: (Less common, often configuration related)
    2. Conditional Commands: (Used for control flow, e.g., if, else)
    3. Browser Commands: (Control the browser itself)
    4. Navigational Commands: (Navigate within the browser)
    5. Wait Commands: (Handle synchronization)

    Browser Commands

    These commands control the browser's behavior.

    Commands Description
    Driver.Navigate().GoToUrl("https://google.com") Open the URL in the browser.
    Driver.URL = "https://google.com" Open the URL in the browser.
    Driver.Manage().Window.Maximize() Maximize the browser window.
    Driver.Manage().Window.Minimize() Minimize the browser window.
    Driver.Manage().Timeouts().ImplicitWait = TimeSpan.FromSeconds(10) Set implicit wait timeout.
    Driver.Navigate().Back() Navigate to the previous page.
    Driver.Navigate().Forward() Navigate to the next page.
    Driver.Navigate().Refresh() Refreshes the current page.
    Driver.Quit() Closes the browser and ends session.
    Driver.close() Close the current browser window.

    Element Interaction

    These commands interact with web elements.

    Commands Description
    Driver.findElement(By locator) Find the element by its locator.
    Driver.findelements(By locator) Find all elements by its locator.
    Element.click() Click on the element.
    Element.SendKeys("text") Type text into the input field.
    Element.clear() Clear the content of a text field.
    Element.Submit() Submit a form.
    Element.GerAttribute("attributeName") Retrieves the value of an attribute.
    Element.GetCssValue("color") Get CSS property value of an element.
    Element.GetText() Retrieves the text content.
    Element.Displayd Check if the element is visible.
    Element.Enabled Check if the element is enabled.
    Element.Selected Check if a checkbox or radio button is selected.

    Handling Alerts and Pop-Ups

    These commands manage browser alerts or pop-ups.

    Commands Description
    IAlert alert = Driver.SwitchTo().Alert(); Switches to the alert window.
    alert.Accept(); Accept the alert (OK button).
    alert.Dismiss(); Dismiss the alert (Cancel button).
    alert.GetText(); Retrieves the text from the alert.
    alert.SendKeys("input text") Send the text to the alert.

    Navigation and Frame Handling

    These commands switch between windows, frames, or iframes.

    Commands Description
    String mainWindowHandle = driver.CurrentWindowHandle; Retrieve the handle of the current window.
    Driver.SwitchTo().Window("windowName"); Switch to a specific browser window.
    IReadOnlyCollection<string> allWindowHandles = driver.WindowHandles; Get a list of all open windows.
    Driver.SwitchTo().Frame("framename"); Switches to a frame or iframe by name.
    Driver.SwitchTo().Frame(frameID); Switches to a frame or iframe by ID.
    driver.SwitchTo().Frame(frameWebElement); Switches to a frame or iframe by element.
    Driver.SwitchTo().ParentFrame(); Switches back to the parent frame.
    Driver.SwitchTo().DefaultContent(); Switches back to the main page content.

    Waiting Commands

    These commands wait for certain conditions to be met before proceeding.

    Commands Description
    driver.Manage().Timeouts().ImplicitWait = TimeSpan.FromSeconds(10); Sets implicit wait.
    new WebDriverWait(driver, TimeSpan.FromSeconds(10)).Until(ExpectedConditions.ElementExists(By.Id("elementId"))); Waits until an element exists.
    Thread.Sleep(3000); Halts execution (not recommended).

    Mouse Actions (Actions Class)

    These commands perform advanced mouse actions.

    Commands Description
    Actions actions = new Actions(driver); Creating an Actions Object.
    actions.MoveToElement(element).Perform(); Hovers over an element.
    actions.ContextClick(element).Perform(); Right-clicks on an element.
    actions.DoubleClick(element).Perform(); Double-clicks on an element.
    actions.DragAndDrop(source, target).Perform(); Drags and drops an element.
    new Actions(driver).ClickAndHold(element).Perform(); Clicks and holds the mouse button.
    new Actions(driver).Release(element).Perform(); Releases the mouse button.

    Handling Dropdowns

    These commands handle dropdown elements.

    Commands Description
    var dropdown = new SelectElement(element); Creates a SelectElement for dropdown.
    dropdown.SelectByText("Option Text"); Selects an option by visible text.
    dropdown.SelectByValue("optionValue"); Selects an option by value.
    dropdown.SelectByIndex(1); Selects an option by index.
    dropdown.DeselectAll(); Deselects all selected options.

    Taking Screenshots

    These commands capture screenshots during test execution.

    Commands Description
    ITakesScreenshot ss = (ITakesScreenshot)driver; Created an screenshot object.
    ss.GetScreenshot().SaveAsFile("screenshot.png", ScreenshotImageFormat.Png); Takes a screenshot and saves it.

    Working with Cookies

    These commands manage cookies for the browser session.

    Commands Description
    driver.Manage().Cookies.AddCookie(new Cookie("name", "value")); Adds a cookie.
    driver.Manage().Cookies.DeleteAllCookies(); Deletes all cookies.
    driver.Manage().Cookies.GetCookieNamed("name"); Retrieves a specific cookie.

    JavaScript Executions (JavaScriptExecutor)

    These commands use JavaScriptExecutor to perform operations not directly supported by Selenium.

    Commands Description
    IJavaScriptExecutor Js = (IJavaScriptExecutor)driver; Create JavaScript property.
    Js.ExecuteScript("arguments[0].click();", element); Clicks on an element using JavaScript.
    Js.ExecuteScript("window.scrollBy(0, 300);"); Scrolls down by 300 pixels.
    ((IJavaScriptExecutor)driver).ExecuteScript("return document.title;"); Retrieves the page title.
    Js.ExecuteScript("argument[0].scrollIntoView(true);", element); Scroll to an element.

    Getting Browser and Page Information

    These commands retrieve information about the browser and web page.

    Commands Description
    driver.Title; Retrieves the page title.
    driver.Url; Retrieves the current page URL.
    driver.PageSource; Retrieves the page source HTML.

    Handling Multiple Windows

    These commands manage multiple browser windows or tabs.

    Commands Description
    driver.SwitchTo().Window(driver.WindowHandles[1]); Switches to the second browser tab.
    driver.Close(); Closes the current tab.
    driver.SwitchTo().Window(driver.WindowHandles[0]); Switches back to the first tab.

    Passing Keyword Commands

    These commands simulate keyboard input.

    Commands Description
    element.SendKeys("Test Input" + Keys.Enter); Simulate Enter key press.
    element.SendKeys(Keys.Control + "a"); Simulate Ctrl+A (Select All).
    element.SendKeys(Keys.Control + "c"); Simulate Ctrl+C (Copy).

    Locators in Selenium

    A locator is an address that uniquely identifies a web element within a webpage. Locators are the HTML properties of a web element that tell Selenium which element to perform an action on.

    Different Types of Web Elements

    The most common elements are:

    • Text box
    • Button
    • Drop Down
    • Hyperlink
    • Check Box
    • Radio Button
    • Timestamp
    • Popup and alert

    Type of locators:

    Locator Type Locator Name Syntax
    id id driver.FindElement(By.Id, 'user-name').SendKeys('standard_user')
    name name driver.FindElement(By.Name, 'password').SendKeys("secret_sauce")
    Link text linkText driver.FindElement(By.LinkText, 'Sauce Labs Backpack').Click()
    Partial link text partialLinkText driver.FindElement(By.PartialLinkText, 'Light').Click()
    Class name className driver.FindElement(By.ClassName, 'submit-button').Click()
    Tag name tagName IList<IWebElement> links = driver.FindElements(By.TagName, 'input')
    Customizable Locators
    CSS selector cssSelector driver. FindElement(By.CSS_SELECTOR, 'input#email').send_keys('abhisheksinghcpj@gmail.com')
    Xpath xpath (See XPath section below for details)

    Methods used:

    • To find and use a single element/value, use FindElement():

      csharp driver.FindElement(By.CssSelector("#app > div > main > article > h3")).Click();

    • To find multiple elements/values, use FindElements():

      csharp driver.FindElements(By.CssSelector("#app > div > main > article > h3")); //Note: You cannot directly use ".Click()" on FindElements, as it returns a collection.

    LinkText and Partial LinkText:

    • We can find an element using the link text or the partial link text in Selenium WebDriver. Both these locators can only be applied to elements with the anchor tag (<a>).
    • The link text locator matches the exact text inside the anchor tag. The partial link text locator matches the text inside the anchor tag partially.
    • NoSuchElementException shall be thrown for both these locators if there is no matching element.

    Example:

    Code:

    driver.FindElement(By.LinkText("click here")).Click();
driver.FindElement(By.PartialLinkText("here")).Click();

    CSS selector Locators

    1. Tag & id: Use hash (#) to join the both attribute

      csharp driver.find_element(By.CSS_SELECTOR,'input#email').send_keys('abhisheksinghcpj@gmail.com'); // or driver.find_element(By.CSS_SELECTOR, '#email').clear(); //for C# driver.FindElement(By.CssSelector("input#email")).send_keys('abhisheksinghcpj@gmail.com');

    2. Tag & class: Use dot (.) to join the both attribute

      csharp driver.find_element(By.CSS_SELECTOR,'input.inputtext').send_keys('abhishekcpj@gmail.com');

    3. Tag & attribute: Use square bracket [] to join attribute

      csharp driver.find_element(By.CSS_SELECTOR,'input[placeholder="Password"]').send_keys('abc123456');

    4. Tag, class & attribute

      csharp driver.find_element(By.CSS_SELECTOR,'button._42ft[type="submit"]').click();

    5. Advance CSS Selector

      • Direct Child Selector (>): .parent > .child
      • Adjacent Sibling Selector (+): .sibling1 + .sibling2
      • General Sibling Selector (~): .sibling1 ~ .sibling2
      • Attribute Selector ([]): input[type='text']
      • ID Selector (#): #myId
      • Class Selector (.): .myClass
      • Universal Selector (*): div *
      • Pseudo-classes and Pseudo-elements: a:hover, ::before

    Selenium XPath

    XPath is a query language for selecting nodes from a web page using XML expressions. By using XPath, we can locate any element on a web page that has an HTML DOM structure.

    Syntax

    //tagname[@attribute='value']

    In the above syntax:

    • //: Selects nodes in the document from the current node that match the selection no matter where they are.
    • tagname: The name of the tag of a particular node.
    • @: Selects attributes.
    • attribute: The name of the attribute of the node.
    • value: The value of the attribute.

    Types of XPath

    XPath is categorized into two main types:

    1. Absolute XPath: The XPath starts from the root of the HTML page.

      • Syntax: /html/body/tag1[index]/tag2[index]/.../tagN[index]
      • Example: /html/body/div[2]/div/div[2]/div/div/div/fieldset/form/div[1]/input[1]

    2. Relative XPath: The path starts from the middle of the DOM structure.

      • Syntax: //htmltag[@attribute1='value1' and @attribute2='value2']
      • Example: //input[@id='passwd' and @placeholder='password']

    XPath Options

    We use different options like AND, OR, contains(), text(), and starts-with().

    AND / OR

    driver.FindElement(By.XPath("//input[@name='keyword' and @placeholder='Search products & brands']")).SendKeys("laptops");

    contains()

    A built-in method used to locate an element based on a partial text match (any text of the whole value). //[contains(@attribute_name, 'attribute_value')]

    starts-with()

    The starts-with() function is used to find the element whose attribute value changes (e.g., message12, message15, message28) on refresh or any operation on the webpage, but the initial text remains the same. //input[starts-with(@attribute_name, 'attribute_partial_value')]

    text()

    Used to find any text value inside the start and end tag (text that appears on the front screen). //tagName[text()='abhi']

    XPath Attributes

    XPath attributes are recommended when you don't have a suitable id or name attribute for the element you want to locate.

    Expression Description
    nodeName Selects all nodes with this name
    / Selects from the root node
    // Selects nodes in the document from the current node that match the selection no matter where they are.
    . Selects the current node
    @ Selects attributes
    .. Selects the parent of the current node
    * Selects any element node
    @* Selects any attribute node
    node() Selects any node
    /audio/file[last()] Selects the last audio file that is a child of an audio element
    /audio/file[1] Selects the first audio file
    /audio/file[position()>4] Selects all audio files that are children of an audio file and have a position greater than 4.
    //[@labeled] Selects all elements with the labeled attribute.
    /audio/file/[price>9.99]/title Selects all the title elements of the file element of the audio element with a price greater than 9.99.

    XPath Axes

    XPath axes are used to search for multiple nodes in an XML document from the current node context. These methods are mainly used when the web element cannot be identified using ID, name, class name, link text, CSS selector, and XPath locators.

    Syntax: XPath = XPath(Current node)//xpath_axes::tagName

    var preceding = driver.FindElements(By.XPath("//a[@id='challenges-link']/parent::li/preceding::*"));
    • self: //self::tagName
    • parent: //parent::tagName
    • child
    • ancestor: Parent of parent
    • descendant: Child of child
    • following
    • following-sibling
    • preceding
    • preceding-sibling
    • following nodes are the nodes below/after the current node in the HTML code.
    • following-sibling nodes are all nodes parallel and below the current node.
    • preceding nodes are the nodes above/before the current node in the HTML code.
    • We can use * as the tagName if we don't know it clearly.
    using OpenQA.Selenium;
using OpenQA.Selenium.Chrome;
using OpenQA.Selenium.Support.UI;
using System;
using System.Collections.ObjectModel;

public class XPathExample
{
    public static void Main(string[] args)
    {
        IWebDriver driver = new ChromeDriver();
        driver.Manage().Window.Maximize();
        driver.Navigate().GoToUrl("[https://owasp.org/www-project-juice-shop/](https://owasp.org/www-project-juice-shop/)");

        string x = driver.FindElement(By.XPath("//a[@id='challenges-link']")).Text;
        Console.WriteLine("display the value for selected path:-> " + x);

        // 1. self axes
        string x1 = driver.FindElement(By.XPath("//a[@id='challenges-link']//self::a")).Text;
        Console.WriteLine("self axes:-> " + x1);

        // parent node
        string p = driver.FindElement(By.XPath("//a[@id='challenges-link']//parent::*")).Text;
        Console.WriteLine("parent axes:-> " + p);

        // ancestor node
        string a = driver.FindElement(By.XPath("//a[@id='challenges-link']//ancestor::ul")).Text;
        Console.WriteLine("ancestor axes:-> " + a);

        // child node
        string c = driver.FindElement(By.XPath("//a[@id='challenges-link']//ancestor::ul/child::li")).Text;
        Console.WriteLine("child node of ancestor axes ->" + c);

        // descendant : child of child node
        ReadOnlyCollection<IWebElement> d = driver.FindElements(By.XPath("//a[@id='challenges-link']/ancestor::ul/descendant::*"));
        Console.WriteLine("lengthe descendant node value :-> " + d.Count);

        // following
        ReadOnlyCollection<IWebElement> folwng = driver.FindElements(By.XPath("//a[@id='challenges-link']//parent::li//following::li"));
        Console.WriteLine("following length ->" + folwng.Count);
        folwng = driver.FindElements(By.XPath("//a[@id='challenges-link']//parent::li//following::*"));
        Console.WriteLine("following node length having tag * ->" + folwng.Count);

        // following-sibling
        ReadOnlyCollection<IWebElement> fs = driver.FindElements(By.XPath("//a[@id='challenges-link']//parent::li//following-sibling::li"));
        Console.WriteLine("following-sibling length ->" + fs.Count);

        // preceding node
        ReadOnlyCollection<IWebElement> preceding = driver.FindElements(By.XPath("//a[@id='challenges-link']//parent::li//preceding::*"));
        Console.WriteLine("lengthe of preceding node -> " + preceding.Count);

        // preceding-sibling node
        ReadOnlyCollection<IWebElement> preceding_sb = driver.FindElements(By.XPath("//a[@id='challenges-link']//parent::li//preceding-sibling::*"));
        Console.WriteLine("lengthe of preceding-sibling node -> " + preceding_sb.Count);

        System.Threading.Thread.Sleep(5000);
        driver.Quit();
    }
}

    XPath Syntax summary

    XPath is used to locate elements on a web page.

    1. Basic Syntax: //tagName[@attribute='value']
    2. Concatenation: //tagName[@attribute='value'][@attribute='value']
    3. Attribute Starts With: //tagName[starts-with(@attribute,'value')]
    4. Attribute Contains Text: //tagName[contains(@attribute,'value')]
    5. Text Value: //tagName[text()='value']
    6. Text Contains Text: //tagName[contains(text(),'partialValue')]
    7. Parent Element: //tagName[@attribute='value']/..
    8. Parent Tag: //tagName[@attribute='value']/parent::tagName
    9. Following Sibling: //tagName[@attribute='value']/following-sibling::tagName
    10. Preceding Sibling: //tagName[@attribute='value']/preceding-sibling::tagName
