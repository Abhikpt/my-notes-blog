    3. Variables in JavaScript

    JavaScript is Loosely Typed

    • No need to specify data types (int, string, etc.)
    • Data type is decided at runtime.

    Variable Keywords

    Keyword ES Version Redeclare Reassign Notes
    var ES5 ✔ Allowed ✔ Allowed Function-scoped
    let ES6 ❌ Not allowed ✔ Allowed Block-scoped
    const ES6 ❌ Not allowed ❌ Not allowed Constant value

    Examples

    var a = 10;     // can redeclare, reassign
let b = 20;     // cannot redeclare, can reassign
const c = 30;   // cannot redeclare, cannot reassign

    4. Data Types in JavaScript

    Primitive Types

    1. Number

    js let a = 10; let b = 23.5; console.log(typeof a); // 'number' 2. String

    js let name = "Rahul Shetty"; 3. Boolean

    js let required = true; 4. Null

    js let x = null; 5. Undefined

    js let y; console.log(typeof y); // 'undefined'

    Type Checking

    typeof variableName;

    5. Operators

    Arithmetic Operators

    • +, -, *, /
    let sum = a + b;
let diff = a - b;

    Assignment Operator

    let c = a + b;

    Negation Operator (!)

    Used for boolean values:

    let required = true;
console.log(!required); // false

    6. Redeclare vs Reassign

    Reassign (Allowed with let)

    let c = 10;
c = 20; // ✔ allowed

    Redeclare

    let c = 10;
let c = 20; // ❌ not allowed

var c = 10;
var c = 20; // ✔ allowed

    const

    • Cannot be reassigned or redeclared
    const x = 10;
x = 20; // ❌ not allowed

    7. Conditions (if-else)

    Syntax

    if (condition) {
    // executes if true
} else if (anotherCondition) {
    // optional
} else {
    // executes if all fail
}

    Example

    const flag = true;

if (flag) {
    console.log("Condition satisfied");
} else {
    console.log("Condition not satisfied");
}

    Negation inside if expression

    if (!flag) { ... }

    Note: flag’s actual value remains true, only the expression is negated.

    8. Loops in JavaScript

    While Loop

    Runs until condition becomes false.

    Structure

    while (condition) {
    // repeated code
}

    Infinite Loop Example

    while (true) {
    console.log("Infinite loop");
}

    Practical Example: Increment Counter

    let i = 0;

while (i < 10) {
    console.log(i);
    i++; // same as i = i + 1
}

    Real-World Automation Example

    • You have 25 links.
    • You want to validate first 10 links.
    • Use loop to iterate through array indices from 0–9.

    function in js:

    • A function is a collection of statements that can be run anywhere at any time.

    • By function declaration:

      function printHello() { console.log(‘Hello’) };

    • By function Expression var printHello = function () { console.log(‘Hello’) }; var printHello = function printFunct() { console.log(‘Hello’) };

    • Using the constructor of the Function object:

      var printHello = new Function(‘console.log(“Hello”)’);
