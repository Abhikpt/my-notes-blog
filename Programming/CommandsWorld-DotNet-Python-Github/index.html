    .NET Commands Cheat Sheet

    A. Dotnet Commands

    • dotnet new nunit → Initialize an NUnit project in the selected folder.
    • dotnet new nunit -n "ProjectName" → Set the project name (internal name used in .csproj and namespace)
    • dotnet new nunit -o "ProjectName" -> Specifies the directory where Nunit project will be created.

    ProjectName. - dotnet new classlib -n FrameworkDesign → Create a Class Library project named FrameworkDesign. - dotnet new specflowproject → Convert the selected folder into a SpecFlow project. - dotnet test --filter UnitTest1 → Run the UnitTest1 file. - dotnet test → Run all tests. - dotnet build → Build the project. - dotnet clean → Clean the project.

    • Adding a Reference Project: 
    dotnet add reference ../ReferencProjName/ReferencProjName.csproj
    • Adding a Project to a Solution: 
    dotnet sln SlnName.sln add path\to\project\ProjectName.csproj

    B. Add the Project in Solution

    1. Navigate to Your Solution Directory 
    cd path\to\your\solution
    1. Add Project Reference to Solution
      sh dotnet sln SlnName.sln add path\to\project\ProjectName.csproj dotnet sln APIAutomation.sln add "RestSharpSpecflow/RestSharpSpecflow.csproj"
    2. Add Project Reference to Another Project
      sh dotnet add reference ../ReferencProjName/ReferencProjName.csproj
    3. Verify the Reference:
    4. Open MySolution.sln in Visual Studio or a text editor.
    5. Confirm the reference is correctly listed under the appropriate project.

    C. NuGet Package Commands

    1. Install a Package:
      sh dotnet add package <package-name>
    2. Add Package Reference to Project:
      sh dotnet add package Newtonsoft.Json
    3. Update a Package to a Specific Version:
      sh dotnet add package <package-name> --version <version>
    4. Remove a Package:
      sh dotnet remove package <package-name>
    5. List Installed Packages:
      sh dotnet list package
    6. Restore Packages:
      sh dotnet restore

    D. Upgrade .NET Version

    1. Install Upgrade Assistant:
      sh dotnet tool install -g upgrade-assistant
    2. Get Available Upgrade Options:
      sh upgrade-assistant --help

    E. Build and Publish the Application

    1. Build the Project:
      sh dotnet build

    2. This compiles your project and places the compiled binaries in the bin directory.

    3. Publish the Application:
      sh dotnet publish -c Release -o ./publish

    4. -c Release → Specifies Release mode. Use Debug for debugging, but Release is preferred for production.
    5. -o ./publish → Specifies the output directory where the published files will be stored.

    Git Commands cheatsheet

    1. Open a Git Repository in VS Code To open any Git repository in VS Code, place the following keyword before https:
    vscode.dev/
    1. Initialize a Git Repository
    git init
    1. Configure Git Before making commits, configure your Git identity (name and email):
    git config list    // display config details
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
    1. Check Repository Status To see which files are staged, unstaged, or untracked:
    git status
    1. Create a New Repository on the Command Line
    echo "# pythonProjectwithRobot" >> README.md
git init                      //initialize the git to folder
git add README.md             //add README file to staging directoy
git commit -m "first commit"  // package all staging changes into a commit object(ID)
git branch -M main            // Move/rename a branch (-m for normaly, -M for forcely )
git remote add origin https://github.com/Abhikpt/pythonProjectwithRobot.git
git push -u origin main      //
    1. Stage Files for Commit Git add is used to add changes to the staging area.
    git add <file1> <file2>  # Stage specific files
git add .                # Stage new and modified files without deleting
git add -a               # Stage all files to the staging area
git add -u               # Stage modified and deleted files
    1. Commit Changes Git saves the state of your project and assigns a unique identifier to the snapshot.
    git commit -m "Your commit message"
    1. View Commit History
    git log
    1. Create a Branch
    git checkout -b <branch-name>
    1. Switch Between Branches
    git checkout <branch-name>
    1. Merge Branches To merge changes from one branch into another (e.g., merging a feature branch into main):
    git checkout main
git merge <branch-name>
    1. Push Changes to Remote Repository
    git push origin <branch-name>
git push
    1. Pull Changes from Remote Repository
    git pull origin <branch-name>
    1. Clone a Repository
    git clone <repository-url>
    1. Revert Commit Changes This command will revert the latest commit (top commit):
    git reset --hard HEAD^
    1. Review Changes Before Commit Always review changes before committing:
    git diff
git diff --staged

    Command Prompt Guide

    Introduction

    Command Prompt is a command-line interpreter available in most Windows operating systems. It allows users to execute commands for file management, directory navigation, and system administration.

    How to Access Command Prompt

    There are multiple ways to open Command Prompt:

    1. Using the Run Command

    • Press Win + R, type cmd, and hit Enter.

    2. Through the Power User Menu

    • Press Win + X and select Command Prompt (or Windows Terminal).
