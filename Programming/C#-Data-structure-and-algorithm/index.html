    1. C# data structure and algorithm

    ## Division of Data Types: 1. Value type 2. Reference type

    A variable of value type directly contains the data, while a variable of reference type just store the reference of Data, which is located somewhere else.

    Value type variable stores it's actual value directly in stack memory. Reference type variable store only reference here in stack, actuale value is located in heap memory.

    • Note: That's why two variable of Value type equal (==) if there data is equal while two variable of reference type will be equal if they referenc the same location

    1. Value Type:

    They are further divided into following categories:

    • Structs
      • Built-in value types
        • Integral numeric type
        • Floating-point numeric types
        • Boolean values
        • Unicode UTF-16 characters
      • Value tuples
      • User-defined struct types
    • Constants
    • Enumerations

    1.1 Integral Number:

    Supported integral types:
    - Byte (byte keyword) --> 8-bit unsigned
    - Sbyte (sbyte) --> 8-bit signed
    - Int16 (short) --> 16-bit signed
    - Uint16 (ushort) --> 16-bit unsigned
    - Int32 (int) --> 32-bit signed
    - UInt32 (unit) --> 32-bit unsigned
    - Int64 (long) --> 64-bit signed
    - UInt64 (ulong) --> 64-bit unsigned

    Different Modes:
    1. Decimal Mode
    No prefix needed, example: 45.

    1. HexaDecimal Mode
      Apply 0x or 0X as prefix , example: 0xff for 255.

    2. Binary Mode
      Apply 0b or 0B as prefix , example: 0b1101110 or 0b_0110_1110 for 110.

    Example:

        int a = -20;
    byte b = 0x0f;
    uint c = 0b1101110;
    Console.WriteLine(a);     //-20
    Console.WriteLine(b);     // 15
    Console.WriteLine(c);     // 110

    Remember that the default value for any built-in integral numeric type is zero.

    1.2 Floating-point numbers:

    It allow us to store floating-point values.You can use three floating-point numeric types:

    1. Single (float) using 32 bits – for example, 1.53f (f or F suffix)
    2. Double (double) using 64 bits – for example, 1.53 (no suffix or d/D suffix)
    3. Decimal (decimal) using 128 bits – for example, 1.53M (m or M suffix)

    Example:

        float temperature = 36.6f;
    double reading = -4.5178923;
    decimal salary = 10000.47M;
    Console.WriteLine(temperature);     //  36.6
    Console.WriteLine(reading);         //  -4.5178923
    Console.WriteLine(salary);          //  10000.47

    Remember that the default value for any floating-point numeric type is zero.

    1.3 Boolean values:

    Regarding Boolean values, you can use the Boolean type or the bool keyword. This makes it possible to store a logical value. It represents one of two values, namely true or false. The default value is false.

    Example:

        bool isTrue = true;
    bool first = isTrue || false; // true
    bool second = isTrue && false; // false
    bool third = 50 > 10; // true

    1.4 Unicode characters:

    It is represented by the Char type or the char keyword. It represents a single Unicode character.

    A char value can be specified using the following: - Character literal – for example, 'a' or 'M' - Unicode escape sequence, starting with \u – for example, '\u25cf' for ● - Hexadecimal escape sequence, starting with \x – for example, '\x107' for ć

    Example:

        char letter = 'M';
    char bullet = '\u25cf';
    char special = '\x107';
    char Test = '\0';      //

    The default value for a char value is \0 (U+0000).

    1.5 Constants

    It is worth noting that you can also define constant values. Each constant value is an immutable value that cannot be changed. Constant values can only be created from simple types.
    You can use the const keyword to create a constant value, as shown in the following line:

    Example:

    
    const int DaysInWeek = 7;

    1.6 Enumerations:

    An enumeration (often called "enum") is a distinct data type that consists of a set of named values called enumerators. Enums are used to represent a collection of related constants in a type-safe way. For example enum CurrencyEnum { Pln, Usd, Eur };

    The constants have automatically assigned values as integer numbers, starting with 0. This means that the Pln constant is equal to 0, while Eur is equal to 2. What’s more, the default value for the enumeration is 0, which means that it is Pln in this case.

    Example:

        CurrencyEnum currency = CurrencyEnum.Pln;
    switch (currency)
    {
    case CurrencyEnum.Pln: /* Polish zloty */ break;
    case CurrencyEnum.Usd: /* American Dollar */ break;
    default: /* Euro */ break;
    }
    enum CurrencyEnum { Pln, Usd, Eur };

    1.7 Value tuples

    The value tuple type is represented by the System.ValueTuple type and is a lightweight data structure that allows you to group multiple data elements of specific types.

    (int, int, double) result = Calculate(4, 8, 13);
